Kajuu Web — Design System
Visual Direction

Kajuu Web must follow a warm boutique fashion style.

The website should feel:

premium
feminine
warm
urban
stylish
trustworthy
handcrafted
mobile-first
not generic
not AI-looking

Avoid:

cold black-and-white editorial style
neon colors
startup SaaS look
cheap ecommerce template feeling
excessive gradients
excessive glassmorphism
random decoration
overcomplicated UI
Brand Mood

Kajuu should feel like a small boutique with strong taste, not a marketplace.

Keywords:

warm boutique
everyday fashion
urban feminine
curated catalog
soft premium
approachable elegance
Color Direction

Suggested palette:

Ivory background: #FFF8F1
Warm beige: #E8D6C0
Soft brown: #8A5A3C
Espresso: #3A2418
Charcoal text: #2E2A27
Muted rose: #C98B7A
Burgundy accent: #7A2E2E
Soft border: #E7D8CC
White card: #FFFFFF

Use warm neutrals as base.

Use burgundy or muted rose only as accents.

Typography

Use a clean premium sans-serif for UI.

Recommended:

Inter
Plus Jakarta Sans
Geist Sans

Typography behavior:

strong headings
readable body
generous line height
not too many font families
avoid decorative fonts for core UI
Layout Principles
mobile-first
generous spacing
strong visual hierarchy
clear sections
image-led catalog
no clutter
no overly symmetrical AI-looking blocks
cards must feel intentional
CTAs must be clear

Product Cards

Product cards must show:

image
product name
price
stock badge
category
WhatsApp CTA or detail link

Cards should not feel like generic marketplace cards.

Badges

Suggested labels:

Nuevo
Destacado
Disponible
Agotado
Consultar stock
Últimas unidades
Mobile Rules

Most users will come from Instagram or WhatsApp.

Mobile must be the priority.

Mobile requirements:

readable typography
thumb-friendly buttons
clear menu
fast catalog browsing
no tiny filters
no cramped product cards
visible WhatsApp CTA
Accessibility
use semantic HTML
visible focus states
proper alt text
readable contrast
buttons must be buttons
links must be links
forms must have labels
Image Direction

Images should feel natural, boutique, and real.

Avoid:

fake AI models if possible
overprocessed stock images
huge unoptimized images
inconsistent crops

Preferred:

vertical product photos
outfit photos
warm natural lighting
consistent crop ratio
UI Principle

Kajuu should feel premium because of spacing, hierarchy, typography, restraint, and taste — not because of random effects.
